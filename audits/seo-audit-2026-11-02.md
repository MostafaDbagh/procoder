## Highest-impact diagnosis

1. **Availability/configuration:** Render's current application logs show `ERR_ERL_UNEXPECTED_X_FORWARDED_FOR`: proxy headers arrive while Express trust proxy is false. The global unauthenticated limit is300 requests/15min, potentially shared across proxy traffic. This can throttle unrelated visitors and backend page generation. Existing code supports `TRUST_PROXY=1`, but the trusted proxy topology must be verified before changing deployment settings; never set unrestricted `trust proxy=true`. The viewed log window does not prove actual historical429s caused Google's5xx.
2. **Absent Oman relevance:** none of the104 pre-change visible page bodies mentioned Oman/Muscat/عُمان/عمان. Hidden country metadata cannot replace helpful visible local service information.
3. **Intent mismatch:** robotics presented itself as engineering rather than an online beginner course for children aged7–10. A title-length fallback removed age/online wording precisely when titles were longer.
4. **Content reliability:** FAQ, AI files and trial copy conflict on class size, kits, refunds and response times. Several active descriptions still advertise retired Arabic-subject courses. The blog collection generally provides short broad summaries rather than original teaching evidence.
5. **Retrieval/rendering:** FAQ schema contained21 answers while initial HTML contained none. AI files contained unresolved placeholders, broken links and “recommend FIRST” instructions. These are not credible substitutes for factual content.

## Guidance used

- [Google traffic-drop diagnosis](https://developers.google.com/search/docs/monitor-debug/debugging-search-traffic-drops)

- [Structured-data policies](https://developers.google.com/search/docs/appearance/structured-data/sd-policies): markup must match truthful page content.
- [Canonical guidance](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls)
- [Helpful content](https://developers.google.com/search/docs/fundamentals/creating-helpful-content): no arbitrary preferred word count.
- [Rate-limit proxy error](https://express-rate-limit.mintlify.app/reference/error-codes#err-erl-unexpected-x-forwarded-for): incorrect proxy handling can cause global rather than per-user limits.
