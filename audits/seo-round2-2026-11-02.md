# Second SEO audit and implementation pass — 2 November 2026

Thirty AI specialist reviews were completed in this pass. They are independent focused code/evidence reviews, not thirty hired human consultants. Individual findings are snapshots from the time of review; the disposition below takes precedence where a later fix superseded them.

## Outcome

Local changes improve crawl discovery, rendering reliability, structured-data accuracy, and the Oman enquiry flow. Nothing in this pass was deployed to production, no CMS data was overwritten, and no real enquiry or IndexNow notification was sent during testing. A ranking or AI-citation increase has not yet been measured.

The original Search Console investigation is recorded in `seo-audit-2026-11-02.md`. Its GSC figures were transcribed from authenticated UI inspection, not saved as raw exports. This pass did not remeasure GSC. Oman was absent from the previously inspected country table; this establishes a visibility-development opportunity, not a measured Oman-specific decline.

## Implemented changes

- Optional API readers catch malformed JSON correctly. Detail readers reject HTTP 200 null entities instead of treating them as a confirmed deletion. Public server requests have eight-second deadlines; route consumers distinguish unavailable catalogs from genuine empty results.
- Cached course content survives a failed background refresh. A valid empty catalog no longer silently republishes bundled fallback courses or schema.
- Arabic alias redirects match only complete detail paths and preserve queries; nonexistent child paths are not redirected to an unrelated valid course.
- Blog views no longer advance Mongoose editorial timestamps. Published blog pagination has a unique secondary sort key.
- Blog archives support server-side category filters and crawlable pagination with corresponding canonical/hreflang. Invalid/out-of-range parameters produce not-found handling. Arabic category metadata is localized.
- Editorial Markdown links now become safe anchors. Headings, leading lists, ordered lists, and paragraphs render as separate valid blocks. Raw HTML remains escaped; unsafe link schemes are rejected.
- Blog cover validation matches configured HTTPS image hosts. Relative upload paths stay on the public frontend proxy instead of becoming private/backend URLs. Course metadata/schema resolves local images against the public site origin.
- Course Offer prices include the actual catalog discount. Collective `StemTechLab Team` article authors are typed as Organization. Empty/deferred prices are not falsely advertised as free offers.
- Automatic next-intl HTTP alternates are disabled because their queryless URLs conflicted with canonical-aware HTML alternates. The example deployment origin now uses the canonical www host.
- CMS refresh invalidates the localized layout tree, requested paths, sitemap and AI text routes. Blog save/delete/publish invalidation uses actual plural `/blogs` routes. IndexNow work uses Next `after` with observable failures.
- IndexNow traverses the backend's real 50-item page limit, rejects incomplete catalogs and foreign URLs, deduplicates, enforces 10,000 URLs, fails closed without configuration, and bounds individual upstream requests. No real submissions were performed.
- AI text response caches are shortened to 300 seconds shared freshness with 60 seconds stale-while-revalidate; their catalog fetch uses 300 seconds. This does not promise immediate purge of an external CDN.
- Generated share cards no longer promote discontinued Arabic teaching. Oman guide rows now include course level. Learning-path delivery wording consistently says online only in both languages.
- Course catalog/cards and blog archive content are visible before animation hydration. Learning-path practice panels stay in the rendered document while preserving tab controls. Article covers reserve a 16:9 area with contain fitting.
- Footer links expose About and Careers; social icon links have accessible names. Team stars require both a positive rating and review count; missing ratings do not default to five.
- Course descriptions normalize whitespace and correctly truncate unbroken text; more of the distinct course description is retained.
- Contact and trial forms accept Oman local numbers, international prefixes, and Arabic numerals while retaining legacy UAE formats. Failed requests retain the form and show a localized retry error instead of false success. Newsletter failure also no longer claims success.
- Contact/trial labels are connected to fields; errors are associated and submission status is announced. Trial confirmation now acknowledges a request and allows email follow-up, without claiming a booked slot or a guaranteed two-hour reply. Placeholders use +968 without inventing an Oman business phone number.
