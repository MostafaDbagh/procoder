## Findings

- **Medium — missing teacher ratings become five stars.** `src/components/MeetOurStars.tsx:367–371` substitutes 5 when `rating` is null/missing; the display condition at line 213 allows a positive rating with zero reviews, displaying five stars without a supporting review count. `../stem-Be/models/Team.js:24–25` also defaults rating to 5 and reviews to 0. This is an unsupported-rating generation path, not proof that any particular teacher's rating is false. Default to absent, and render a rating only when backed by an identified review dataset; expose its provenance.
- **Medium — Careers does not server-render jobs and masks request failures as no vacancies.** `src/app/[locale]/careers/CareersContent.tsx:45–61` starts empty/loading and fetches only in `useEffect`; `catch` resets to an empty list, which line 84 turns into the normal no-positions message. Description, requirements and application anchors are additionally conditional on clicking a row (`:126`). Meanwhile `careers/page.tsx:13–15` always advertises active instructor hiring. Fetch jobs server-side, distinguish unavailable data from a verified empty inventory, and align hiring metadata with actual status. This is a rendering/reliability gap, not evidence that Google never executes JavaScript or that current hiring is false.
- **Low — expertise cannot be followed from bylines to profiles.** Blog author name is plain text (`src/app/[locale]/blogs/[slug]/BlogDetailClient.tsx:81–84`); Article author schema has only type/name (`page.tsx:97`). Teacher names are headings, not profile links (`MeetOurStars.tsx:201–203`), and bios longer than 120 characters are initially truncated with click-only expansion. Link actual authors to stable biographies with relevant experience, qualifications and authored work. Do not invent author identities or certifications. Current About metadata claims certified teachers, but this component supplies no dedicated credential/provenance link.
